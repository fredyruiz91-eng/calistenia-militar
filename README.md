# Calistenia Militar

Repositorio de rutinas de calistenia con enfoque militar: fuerza, resistencia, disciplina y progresión. Incluye rutinas en Markdown y una pequeña app web con temporizador para seguir los circuitos.

## ⚠️ Aviso importante
Este material es educativo y no sustituye la supervisión de un entrenador o médico. Si tienes lesiones, dolor o enfermedades, consulta antes de empezar. Calienta siempre y prioriza la técnica sobre las repeticiones.

## 🚀 Cómo usar este repositorio

1. Lee una rutina según tu nivel:
   - [Principiante](rutinas/principiante.md)
   - [Intermedio](rutinas/intermedio.md)
   - [Avanzado](rutinas/avanzado.md)
   - [Reto militar 21 días](rutinas/militar-21-dias.md)
2. Consulta la técnica de cada ejercicio en la carpeta [`ejercicios/`](ejercicios/).
3. Registra tus sesiones en [`progreso/registro.md`](progreso/registro.md).
4. Abre la app web `index.html` o activa GitHub Pages para usarla desde el móvil.

## 🌐 Usar la app web con GitHub Pages

1. Ve a **Settings → Pages**.
2. En **Branch**, selecciona `main` y carpeta `/ (root)`.
3. Guarda y espera unos minutos.
4. GitHub te dará una URL para abrir `index.html` desde el navegador.

## 🧱 Estructura

- `rutinas/`: planes de entrenamiento por nivel.
- `ejercicios/`: técnica, progresiones y errores comunes.
- `datos/ejercicios.json`: datos de ejercicios para futuras apps.
- `progreso/registro.md`: plantilla para registrar avances.
- `assets/`: imágenes, banners o recursos.
- `index.html`, `styles.css`, `app.js`: app simple con temporizador.

## 📌 Reglas de progresión

- Semana 1-2: técnica y adaptación.
- Semana 3-4: aumenta 1-2 repeticiones o 5-10 segundos por serie.
- Si no completas la técnica, retrocede una progresión.
- Descansa al menos 48 h entre sesiones del mismo grupo muscular.
